## SafetyDump projection (the parity target)

Per case, a stable, UID/timing-free projection:

```
SAFETY
VERDICT <ok|violated-invariant|violated-initial|deadlock|assumption-false|
         assumption-error|violated-property|error>
EC <primary-error-code>                 (0 on success)
INV <name>                              (invariant-violation verdicts)
STAT generated|distinct|queue|depth <n>
STAT outdegree <min> <mean> <p95> <max> (success runs, when collected)
COVERAGE <action-or-line> <count>       (only with -coverage)
TRACE <count>
STATE <num> <fp-unsigned-hex|-1>
LABEL <action label / <Initial predicate> / Stuttering / Back to state>
<state variable bindings, verbatim TLC rendering>
ENDSTATE
```

Source of each field (recorded EC code → args):

- verdict/EC: priority scan of recorded codes — 2104/2105 (assumption),
  2107 (invariant-initial), 2110/2146 (invariant-behavior), 2114 (deadlock),
  2116 (temporal, WU8), else 2193 (success)→ok, else lowest recorded 21xx.
- stats: `TLC_STATS` (2199) `[generated, distinct, queue]`,
  `TLC_SEARCH_DEPTH` (2194), `TLC_STATE_GRAPH_OUTDEGREE` (2268, success only,
  when workers collected observations).
- trace: `TLC_STATE_PRINT2` (2217) records the `TLCStateInfo` object + ordinal;
  action label = `info`, bindings = `state.toString()`, fingerprint =
  `state.fingerPrint()` (unsigned 64-bit hex). Initial-state violation embeds
  the offending state string in the `TLC_INVARIANT_VIOLATED_INITIAL` record's
  2nd arg (no separate STATE_PRINT2); rendered as the length-1 trace, fp `-1`.
- coverage: `TLC_COVERAGE_INIT` (2773) / `TLC_COVERAGE_NEXT` (2772), keyed by
  action location.

SafetyDump runs `-workers 1 -fp 0 -checkpoint 0 -cleanup -noGenerateSpecTE`
so the BFS order, fingerprint polynomial (FP64 index 0), and stats are
deterministic. Per-case extra tlc args live in `opts.txt` (e.g. `-coverage 1`).

## Classification of ModelChecker/Tool safety branches

- **required** (7.1–7.7): init/next generation, assumption check, invariant
  check + order, state/action constraints, deadlock (flag-honoring), BFS
  order/depth/queue discipline, predecessor store + shortest trace (invariant,
  deadlock, initial), FP64 fingerprint + FPSet membership/distinct, symmetry
  canonicalization + reduced counts + unsafe-option rejection, generated/
  distinct/queued/depth/outdegree stats, action/cost coverage counters,
  progress events, checkpoint/resume as a behavioral (not byte) contract.
- **deferred**: implied-temporal / liveness property checking, `TLC_BACK_TO_STATE`
  lasso and `TLC_STATE_PRINT3` stuttering traces (WU8); TLC RNG/simulation
  parity and on-disk checkpoint byte format (WU9); StandardModule override
  registry (family 4) and `UniqueString` order (family 5) — any operator reached
  without a native/core impl returns a typed unsupported result.
- **excluded**: `DFIDModelChecker`/DFID, distributed/multi-worker `Worker`
  threading + fingerprint distribution, `DiskFPSet`/`OffHeap`/`MultiFPSet` disk
  tiering, `DiskStateQueue` byte layout, JMX/telemetry, trace-exploration spec
  (`-generateSpecTE`) generation.

value/impl fingerprint contributors (`TLCState.fingerPrint` extends FP64 over
each value): required = the family-1..3 kinds already inventoried at 6.8
(bool/int/string/SetEnum/FcnRcd/interval-as-SetEnum/tuple+record-as-FcnRcd/
model). Deferred = family-4 override values, family-5 UniqueString-token model
identity (6.8 folds the NAME instead — approved difference). Excluded = disk
FPSet encodings.

## Frozen baseline (pre-7.1 check.hoon)

The current safety search (`desk/lib/tla/check.hoon`, post-6.9) already runs on
Work Unit 3 semantic nodes via `node-eval` (`init-states`/`next-states`/
`pred-bool`), NOT the CST. What 7.1+ must still replace/add:

- **state key = rendered string.** `++fingerprint` builds a sorted
  `"var=<render:ev value>;"` cord; the visited map is keyed by that text. 7.1
  replaces it with FP64 over 6.8 `fp-input` bytes; no rendered text in any key.
- **single invariant.** `bfs-opts` carries one optional invariant name+body
  (`inv.o`/`ivsb`); 7.3 generalizes to an ordered list.
- **no assumptions, implied-init/action, state/action constraints, symmetry,
  coverage.** None are wired into the search setup.
- **predecessor-pointer traces only.** `seen-entry`=[depth pred], `visit`, BFS
  gives shortest trace by construction; no FP64, no per-state action metadata
  beyond the Next-body span label. 7.4 formalizes `pred-store`.
- **stats:** generated/distinct/depth only (outdegree, queued-at-report,
  coverage absent).
- The five `gen-mc-tests` goldens (`tests/lib/tla/mc`, verdict+trace+counts)
  stay green as the smoke suite; the `safety/` corpus is the parity target they
  cannot express.

Residual CST solver (`++gen`/`++filter`/`++gen-conj`/…, lines ~100–228) is used
only by simulation and the liveness property scan (WU8/WU9 residue), not the
safety BFS.
